# 아스트랄 아트리에

C# / Windows PC 과제용 마법학교 턴제 전투 게임입니다.
마우스로 **공격·방어·버프 버튼**을 클릭해 던전의 적을 처치하고, 학점 **10점**을 모으면 클리어합니다.

## 실행

- Visual Studio에서 `AstralAtelier/AstralAtelier.sln`을 열어 실행합니다.
- .NET 9 Windows Desktop 런타임이 필요합니다.
- 프로젝트 폴더에서 `dotnet run --project AstralAtelier.csproj`로 실행할 수도 있습니다.
- 빌드와 게시 시 `resource` 폴더를 실행 파일 옆으로 자동 복사합니다.

## 전체 진행

```text
타이틀 → 새 게임 → 아카데미 → 던전 입장 → 전투
                                            ↓
                               승리: 학점 +1~3
                                ├─ 10점 미만 → 아카데미
                                └─ 10점 달성 → 게임 클리어

                               패배: 플레이어 HP 0
                                └─ 게임 오버
```

- 아카데미의 **던전으로** 버튼으로 다음 전투에 입장합니다.
- 전투 입장마다 플레이어와 적의 HP, 방어, 버프를 초기화합니다.
- 적은 현재 에셋 두 종류인 **흑요석 몬스터 → 용암 몬스터 → 흑요석 몬스터…** 순서로 반복합니다.
- 적마다 같은 수치를 사용하며 레벨이나 성장 시스템은 없습니다.
- 게임 클리어 화면에서 **다시 시작** 또는 **메인 화면**을 선택합니다.
- 게임 오버는 기존 이미지 화면을 사용하며, **새 게임**으로 재시작하거나 **종료**로 게임을 닫습니다.
- ESC를 누르면 메인 화면으로 돌아갑니다. 새 게임은 모든 진행을 초기화합니다.

## 전투

플레이어가 먼저 행동하고, 적이 살아 있으면 적이 한 번 행동합니다.
적은 공격·방어·버프 중 하나를 같은 확률로 무작위 선택합니다.
턴 결과를 확인한 뒤 **다음 턴** 버튼으로 진행합니다.

| 항목 | 플레이어 | 적 |
| --- | ---: | ---: |
| 최대 HP | 100 | 60 |
| 기본 공격 피해 | 20 | 12 |
| 방어 감소량 | 15 | 10 |
| 다음 공격 버프 | +20 | +8 |

### 공격

- 즉시 상대에게 피해를 줍니다.
- 피해 = 기본 공격 + 자신의 버프 - 상대의 방어.
- 피해는 0 미만이 될 수 없고, HP도 0 미만이 되지 않습니다.
- 공격하면 자신의 버프와 상대의 방어를 제거합니다.
- 플레이어가 적을 처치한 턴에는 적이 행동하지 않습니다.

### 방어

- 다음에 받을 공격의 피해를 감소시킵니다.
- 상대가 방어나 버프를 사용하면 방어 효과는 유지됩니다.
- 공격을 한 번 받으면 방어 효과를 제거합니다. 피해가 0이어도 소모됩니다.
- 반복 사용해도 중첩되지 않고 정해진 감소량을 유지합니다.

### 버프

- 다음 공격의 피해를 증가시킵니다.
- 방어를 사용해도 버프는 유지됩니다.
- 다음 공격에 적용한 뒤 제거합니다.
- 반복 사용해도 중첩되지 않고 정해진 증가량을 유지합니다.

도형 그리기, 제한시간, 입력 완성도, 입력 속도, 행동 간 상성은 사용하지 않습니다.

## 학점과 종료

- 적 한 마리를 처치할 때마다 학점 **1~3점**을 무작위로 받습니다.
- 사용 턴 수나 행동 속도는 학점에 영향을 주지 않습니다.
- 학점은 최대 **10점**까지 표시합니다. 마지막 보상이 남은 학점보다 크면 10점에 맞춥니다.
- 누적 학점 10점이면 게임 클리어입니다.
- 플레이어 HP가 0이면 게임 오버이며, 패배 보상은 없습니다.

## 화면과 사운드

- 타이틀: 아카데미 배경, 새 게임·종료 버튼, 게임 안내.
- 아카데미: 현재 학점, 처치한 적 수, 던전 입장·메인 화면 버튼.
- 전투: 양쪽 HP, 방어·버프 수치, 캐릭터 이미지, 행동 버튼, 턴 결과.
- 승리: 획득 학점과 누적 학점.
- 클리어: 전용 클리어 이미지, 최종 학점, 처치 수, 다시 시작·메인 화면 버튼.
- 게임 오버: 기존 게임 오버 이미지, 최종 학점, 처치 수, 새 게임·종료 버튼.
- 타이틀·아카데미·클리어에서는 타이틀 BGM, 전투·승리에서는 전투 BGM, 게임 오버에서는 게임 오버 BGM을 재생합니다.

## 코드 구성

| 파일 | 역할 |
| --- | --- |
| `GameMain.cs` | 타이틀·플레이 화면 전환과 BGM 관리 |
| `SceneTitle.cs` | 타이틀 입력과 표시 |
| `SceneBattle.cs` | 아카데미·전투·결과·종료 화면 입력과 표시 |
| `GameSession.cs` | 전투 수치, 공격·방어·버프, 학점, 적 순환, 승패 판정 |
| `GameUi.cs` | 버튼, 문자열, HP 바 등 공통 UI |
| `UiText.cs` | 리소스 JSON에서 화면 문구 읽기 |
| `BgmManager.cs` | BGM 재생과 반복 |
| `glc2d/` | WinForms / Direct2D 기반 게임 프레임워크 |

## UI 리소스

게임에서 사용하는 패널·버튼·HP 바·테두리는 코드로 도형을 그리지 않고 PNG 리소스를 읽어 표시합니다.
HP, 학점, 피해량처럼 바뀌는 값은 이미지 위에 문자열로 표시합니다.

| 경로 (`AstralAtelier/resource/` 기준) | 내용 |
| --- | --- |
| `ui/panels/` | 어두운 패널, 아카데미 오버레이, 검은 배경 |
| `ui/buttons/` | 색상별 버튼과 마우스를 올렸을 때의 버튼 |
| `ui/hp/` | HP 바 배경, 플레이어·적 HP 색상 |
| `ui/frames/` | 색상·두께별 테두리 |
| `ui/choice/` | 기존 공격·방어·버프 아이콘 |
| `ui/system/` | 기존 새 게임·종료 등 버튼 이미지 |
| `ui/texts.ko.json` | 화면 제목, 안내, 버튼 이름, 숫자 표시 형식 |
| `ui/assets.json` | UI 텍스처 파일 목록 |
| `background/gameover.png` | 기존 게임 오버 화면 이미지 |
| `background/gameclear.png` | ImageGen으로 만든 게임 클리어 화면 이미지 |

버튼과 테두리는 24×24 이미지의 모서리를 유지하고 가운데만 늘려 표시합니다.
문구를 바꾸려면 `texts.ko.json`의 값을 수정하고, 디자인을 바꾸려면 해당 PNG를 교체합니다.
기본 UI PNG를 다시 생성하려면 저장소 최상위에서 `./tools/ExportUiAssets.ps1`을 실행합니다.
모든 리소스는 빌드·게시 시 실행 파일의 `resource` 폴더로 자동 복사됩니다.

## 규칙 검증

저장소 최상위에서 실행:

```powershell
dotnet run --project tests/GameRulesChecks.csproj
```

그래픽이나 추가 테스트 패키지 없이 실제 전투 규칙 코드를 검증합니다.
공격·방어·버프의 유지와 소모, 중복 입력 차단, 보상 중복 방지, 적 순환, 학점 상한, 클리어·게임 오버·재시작을 확인합니다.
